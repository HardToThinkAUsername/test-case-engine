# 在线商城需求文档

## 1. 项目概述

在线商城系统，支持用户浏览商品、下单购买、支付、查看订单状态。

## 2. 用户角色

- **普通用户**：浏览商品、下单、支付、查看订单
- **管理员**：管理商品、查看订单、处理退款

## 3. 功能需求

### 3.1 用户注册与登录

**用户故事**：作为一个用户，我想注册账号并登录，以便使用商城功能。

**功能描述**：
- 用户可以通过手机号或邮箱注册
- 注册时需要设置密码（至少8位，包含字母和数字）
- 支持手机号+验证码登录
- 支持邮箱+密码登录
- 登录后保持会话，7天内免登录

**异常处理**：
- 手机号已注册：提示"该手机号已注册"
- 验证码错误：提示"验证码错误，请重新输入"
- 密码错误：提示"密码错误，还剩N次机会"
- 连续5次密码错误：账户锁定30分钟

### 3.2 商品浏览

**用户故事**：作为一个用户，我想浏览商品列表和详情，以便选择要购买的商品。

**功能描述**：
- 商品列表支持分页（每页20条）
- 支持按分类筛选
- 支持按价格排序（升序/降序）
- 商品详情显示：名称、价格、描述、库存、图片
- 库存为0时显示"缺货"

### 3.3 购物车

**用户故事**：作为一个用户，我想将商品加入购物车，以便一起结算。

**功能描述**：
- 可以将商品加入购物车
- 可以修改购物车中商品的数量
- 可以从购物车中删除商品
- 购物车商品数量不能超过库存
- 结算时校验库存

### 3.4 下单与支付

**用户故事**：作为一个用户，我想提交订单并完成支付，以便购买商品。

**功能描述**：
- 选择购物车中的商品提交订单
- 填写收货地址
- 选择支付方式（支付宝/微信）
- 订单金额计算：商品价格 × 数量
- 支付超时时间：30分钟
- 支付成功后扣减库存

**异常处理**：
- 库存不足：提示"库存不足，无法下单"
- 支付超时：订单自动关闭
- 支付失败：提示"支付失败，请重试"
- 重复支付：自动拦截

### 3.5 订单管理

**用户故事**：作为一个用户，我想查看我的订单状态，以便了解物流信息。

**功能描述**：
- 订单列表：显示所有订单
- 订单详情：显示商品、金额、状态、物流
- 订单状态：待支付 → 已支付 → 已发货 → 已完成
- 支持取消未支付的订单
- 支持确认收货

**异常处理**：
- 已支付订单不能直接取消，需要申请退款
- 已发货订单不能取消

### 3.6 退款

**用户故事**：作为一个用户，我想申请退款，以便在不满意时退回款项。

**功能描述**：
- 已支付未发货的订单可以申请退款
- 退款金额 = 订单金额
- 退款原路返回
- 退款到账时间：1-3个工作日

## 4. 非功能需求

- 页面加载时间 < 3秒
- 支持1000并发用户
- 数据每日备份
